# Start Enterprises

A responsive static website for Start Enterprises, ready to deploy with GitHub Pages.

## Run locally

Open `site/index.html` in a browser. The page uses Google Fonts when an internet connection is available and includes system-font fallbacks.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Set the build and deployment source to **GitHub Actions**.
4. The included workflow deploys `site/` on every push to `main`. After the first successful run, the public site URL appears under **Settings → Pages** and in the workflow run.

GitHub Pages is a static host. Update the copy and styling in `site/index.html` before publishing if you want to add verified company details, contact information, or a more specific description of the business.
